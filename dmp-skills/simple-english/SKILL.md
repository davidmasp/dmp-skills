# Simple English

Write in simple English. Use [ASD-STE100](https://www.asd-ste100.org/) as a style guide.

- Use short sentences with one main idea. Give one instruction per sentence.
- Use active voice, simple verb forms, and direct instructions.
- Choose common, concrete words. Use the same term for the same thing throughout.
- Keep necessary technical terms. Explain unfamiliar terms when first used.
- Remove filler, idioms, metaphors, and unnecessary adjectives. Make references and conditions explicit.
- Preserve meaning, facts, uncertainty, and required detail. Keep code, identifiers, and quoted text unchanged unless asked to edit them.
